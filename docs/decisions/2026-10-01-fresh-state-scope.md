# Fresh geographic test scope
Decision: the fresh-state test uses UK (existing held-out cells) and AP. KA, TN and KL have only reserve and buffer cells in the grid, so they contribute nothing; reserve cells stay descriptive only.
Why: the grid roles show AP cells as unused by fitting, UK as held out, and KA/TN/KL only as reserve/buffer. Fire-data completeness for the southern strip is recorded in the research repository (no missing chunks, no duplicates).
